# 策略定義與版本

預設策略是可解釋的橫斷面因子排名，並非已證實有預測能力的模型。完整研究方法及限制見 [strategy_validation.md](strategy_validation.md)。

`config/alpha_strategy.yaml` 是實際權重來源：5日動能、20日動能與20日波動扣分，先縮尾再 z-score。FeatureEngine 另外可計算10日動能、可得市場相對強弱、法人股數比例、月營收成長/加速度及回撤；有提供欄位不代表預設Alpha已使用該因子。缺資料維持缺值，預設排除；顯式重新正規化也有最低資料覆蓋要求。

Gemini 依截止前可得證據、排名、已結算持股及成本工具自主選擇候選、regime與目標配置。Optimizer只回傳檢查與有界調整建議；修改配置要回到Agent重新確認。整張訂單由前日NAV與官方未調整收盤機械推導，模型沒有任意改訂單股數的接口。

法定股票/現金/整張/持股數/Active Share約束與內部周轉、不交易區間、安全門檻分開記錄。產業分類缺少可信時點或來源不推測；未知分類另列。沒有完整基準持股或主辦方AS口徑時不能正式通過。

equal_weight、momentum與multifactor在相同成本和約束下比較，全部結果保留，不以最終測試調參。固定2026股票名單的歷史研究含選樣偏誤；未知公布時點營收不納入嚴格歷史回測，研究假設不是歷史可得證明。

策略聲明由Agent產生並以原始Word範本填入，經視覺QA後凍結。實際文字、模型trace及金融結果保留本機，不放入公開PR。策略或因子改版應重跑驗證及確認聲明一致性，不靜默替換已凍結版本。

`decision-source.zip` 與每輪輸入保存決策相關版本。`replay-decision`只重現已捕捉決策的確定式處理，不重新抽樣Gemini輸出，也不宣稱重播能證明策略獲利。
